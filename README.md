# Дім Млинців

Односторінковий сайт кав'ярні в Ужгороді.

> **Це навчальний макет.** Частина позицій меню — чернетки: їхні назви й ціни
> ще не підтверджені закладом, тому на самих картках стоїть бейдж «чернетка».
> Не орієнтуйтесь на них як на справжнє меню. Знімки страв — стокові
> (Unsplash), до зйомки закладу.

## Стек

Один файл `index.html`: розмітка, стилі в `<style>`, скрипти в `<script>`.
Звичайний CSS, vanilla JS, без збірки й без залежностей.

| Файл | Що це |
|---|---|
| `index.html` | увесь сайт |
| `serve.py` | локальний сервер для перегляду |
| `check.py` | перевірка сайту: контраст, прокрутка, таб-порядок, цілі дотику |
| `favicon.svg`, `og.png` | іконка й картка для месенджерів |

## Запуск

```bash
py serve.py
```

Відкриється на `http://localhost:8931`. Кеш вимкнено навмисно: `http.server`
не шле `Cache-Control`, і браузер показує стару сторінку після правок.

## Перевірка

```bash
py check.py            # знімки + усі перевірки
py check.py --audit    # тільки перевірки, без знімків
```

Потрібен Playwright:

```bash
py -m pip install playwright && py -m playwright install chromium
```

`check.py` міряє контраст **із фактичних пікселів знімка**, а не з CSS —
напівпрозорий шар поверх градієнта у файлі не видно. Перевіряє також
недосяжний контент, обхід клавіатурою, переповнення тексту через `Range`,
накладання блоків і цілі дотику ≥44×44.

Він знімає з `prefers-reduced-motion`, тож рух у ньому вимкнено: після робіт
з анімацією потрібен окремий прогін із увімкненим.

## Що всередині

Меню як сцена — одна страва в кадрі, перемикається стрілками й фільтром
категорій. Міні-сторінка страви з перельотом кадру через View Transitions.
Живі години за Europe/Kyiv. Кошик у `localStorage`. Перемикач теми на три
стани. Тексти українською.
